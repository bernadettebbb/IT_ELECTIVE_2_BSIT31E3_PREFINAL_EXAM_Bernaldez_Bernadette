# IT Elective 2 - Prefinal Exam

A clean and simple ASP.NET Core MVC web app that's made for our IT Elective 2 prefinal exam.

---

### Features
* **Simple Card Layout** – Clear, easy-to-read cards for questions and answers using Bootstrap 5.
* **Muted Pink & Sage Theme** – Soft, comfortable aesthetic for late-night studying.
* **Responsive Design** – Adapts smoothly on laptop, tablet, or phone screens.

---

### Tech Stack
* **Framework:** ASP.NET Core MVC
* **Language:** C#
* **Frontend:** Razor Views (`.cshtml`), CSS3, Bootstrap 5

---

### How to Run

1. Open the project in **Visual Studio 2022**.
2. Press `Ctrl + Shift + B` to build the solution.
3. Press `F5` or click **Run** to launch it in your browser (`http://localhost:5168`).
